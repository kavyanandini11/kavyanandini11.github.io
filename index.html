04 / Generative AI · RAG · NLP

RAG Research Paper Assistant

Upload research papers as PDFs, ask questions in plain English, and get answers grounded only in those papers — each one cited with the document name, page number, and the supporting excerpt. If the papers don't contain the answer, the assistant says so instead of guessing.

Multi-PDF
Cross-paper search
Page-level
Citations
384-d
MiniLM embeddings
5
REST endpoints
  • End-to-end retrieval-augmented generation pipeline: PDF upload → page-aware extraction with PyMuPDF → cleaning → overlapping, word-safe chunking → embeddings → FAISS vector index
  • Local sentence-transformers embeddings (all-MiniLM-L6-v2) with cosine-similarity top-K retrieval, per-paper filtering, and a similarity threshold that skips the LLM when no evidence is found
  • Strict grounded-generation prompt with [file, p. N] citations and a fixed refusal when the evidence is insufficient; follow-up questions are rewritten into standalone queries so chat history is never used as evidence
  • Persistent index with per-document deletion and SHA-256 duplicate detection; upload validation (PDF signature, size limit, sanitised filenames) and structured API errors
  • FastAPI REST backend with a responsive HTML/CSS/JS interface, Docker support, a pytest suite, and an evaluation script reporting hit@k and MRR for retrieval
  • Works with any OpenAI-compatible LLM — including local models through Ollama
Python FastAPI RAG LLMs FAISS sentence-transformers PyMuPDF Pydantic Docker pytest
