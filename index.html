02 / Selected Work

Projects I've built.

A selection of machine learning and applied AI projects — from predictive models in healthcare to real-time computer vision systems.

01 / NLP · Transformers 2026

AI Notes Summarizer

An abstractive text summarization tool built on the BART transformer model via Hugging Face. Students paste in lecture notes, articles, or long study material and receive a clean, condensed summary tuned for revision.

  • Fine-tuned facebook/bart-large-cnn from Hugging Face for abstractive summarization
  • Pre-processing pipeline with tokenization, chunking, and length normalization for long inputs
  • Streamlit web interface with adjustable summary length and ROUGE-based evaluation
Python Hugging Face BART Transformers PyTorch Streamlit
02 / Machine Learning · Healthcare January 2026

Drug Prediction System

A machine learning system that recommends drugs, dosages, and treatments based on patient features. Built with XGBoost on processed medical datasets to assist clinical decision-making and reduce prescription errors.

  • XGBoost classifier trained on processed medical datasets with engineered patient features
  • Full evaluation across accuracy, precision, recall, and confusion matrix to validate predictions
  • Hyperparameter tuning and cross-validation to improve generalization and reduce overfitting
  • Designed as a decision-support tool for doctors, not a replacement — flags recommendations with confidence scores
Python XGBoost scikit-learn Pandas NumPy Matplotlib
03 / Real-Time ML · Time Series 2026

Real-Time Stock Price Prediction Dashboard

A live dashboard that pulls real-time stock market data and forecasts short-term price movements using an LSTM neural network. Built to demonstrate time-series forecasting end-to-end — from streaming data to model predictions visualized live.

  • Live market data via the yfinance API, refreshed at fixed intervals
  • LSTM model trained on historical price sequences for short-horizon forecasting
  • Interactive Streamlit dashboard with Plotly charts showing actual vs predicted prices
  • Confidence intervals and rolling RMSE displayed alongside predictions for honest evaluation
Python TensorFlow LSTM yfinance Streamlit Plotly
